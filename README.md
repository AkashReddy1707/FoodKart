
# FoodKart – Online Food Delivery Website

FoodKart is an online food delivery web application project built using HTML, CSS and JavaScript.

## Features

- Restaurant listing interface
- Restaurant menu display
- Shopping cart functionality
- Add and manage cart items
- Cart data persistence using localStorage
- Location and map interface using Leaflet
- Login and signup user interface

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- Browser localStorage

## Project Structure

FoodKart/

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open home.html in your browser.
4. Explore the FoodKart interface.
